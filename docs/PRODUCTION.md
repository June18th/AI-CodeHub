# 生产环境升级清单

## 🔐 安全

| 项目 | 当前状态 | 生产要求 | 优先级 |
|------|----------|----------|--------|
| JWT Secret | 硬编码默认值 `ai-codehub-2026-...` | 通过环境变量注入，≥256位随机值，禁止默认 | 🔴 高 |
| API Key 存储 | `.env` 明文 | AES 加密存储 / HashiCorp Vault / 云 KMS | 🔴 高 |
| HTTPS 证书 | 自签证书 `config/certs/` | Let's Encrypt 或 CA 签发证书，TLS 1.3 only | 🟡 中 |
| Redis 密码 | 有默认值 `redis123` | 移除默认值，强制 env，高强度随机密码 | 🟡 中 |
| MySQL 密码 | 有默认值 `root123` | 移除默认值，强制 env | 🟡 中 |
| CORS | 未配置 | 配置允许来源白名单 | 🟡 中 |
| SQL 日志 | `Slf4jImpl` | 生产环境关闭 SQL 日志或设为 WARN | 🟢 低 |

## 🗄️ 数据持久化

| 项目 | 当前状态 | 生产要求 | 优先级 |
|------|----------|----------|--------|
| MySQL | 单节点，无备份 | 主从复制 + 定时全量备份 + binlog 增量备份 | 🔴 高 |
| Redis | 单节点，AOF 已开启 | 哨兵/集群模式，持久化到磁盘 | 🔴 高 |
| ES | 0 副本，1 分片 | ≥1 副本，分片数按数据量规划 | 🟡 中 |
| MinIO | 本地绑定挂载 | 对象存储或分布式 MinIO 集群 | 🟡 中 |
| 日志 | Promtail → Loki 本地存储 | Loki 配置远程存储（S3/GCS） | 🟢 低 |

## 📈 监控与告警

| 项目 | 当前状态 | 生产要求 | 优先级 |
|------|----------|----------|--------|
| Metrics | Prometheus + Grafana 已部署 | 添加告警规则（错误率、延迟、磁盘、内存） | 🔴 高 |
| 告警通知 | 无 | 钉钉/飞书/邮件 Webhook 推送 | 🔴 高 |
| Uptime | 无 | 健康检查端点 + 外部探活 | 🟡 中 |
| KPI 仪表盘 | Grafana JVM Dashboard | 业务指标 Dashboard（DAU、Token 用量、收入） | 🟢 低 |

## ⚡ 性能

| 项目 | 当前状态 | 生产要求 | 优先级 |
|------|----------|----------|--------|
| JVM 参数 | 已配置 G1GC, 256m-512m | 根据负载调优，增加 GC 日志，JMX 监控 | 🟡 中 |
